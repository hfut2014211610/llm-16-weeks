## 今日 AI 新闻

今天官方日报写的是“安静，无大事”，但昨天下午到今天有几条技术向的值得看，偏架构、推理和 harness。

### 字节 Seed 的 Recycler：隐藏状态回收做潜在推理
把上一个 token 的顶层隐藏状态，经轻量适配器和当前 token 的嵌入一起送进下一步，解码开销几乎不变，却保留了跨步的连续语义。它覆盖预训练、SFT、继续预训练和 RL 全流程，在数学和推理任务上参数效率突出。和“注意力与记忆、前沿架构”直接相关。
[aihot 条目](https://aihot.news/items/dtv2x9u7nafgurzsmsfjy4cec)

### TokenGate：给现有 LLM 加可学习 token 剪枝
斯坦福和 UC Berkeley 的模块，在 Qwen3-1.7B 上让 TTFT 加速 1.4x 到 11.3x，峰值 prefill 显存降低 1.5x 到 3.4x，据称无精度损失。长上下文 prefill 是推理的大头，这是一条不动底座、只加门控的思路。和注意力、推理效率有关。
[aihot 条目](https://aihot.news/items/b9a13c9a3uxo2qe2bwud0e129)

### KRAFTON Raon-1 mini：MoE 加线性注意力的开源小模型
从头训练的 30B-A4B 预览版，混合专家加线性注意力，Apache 2.0 开源，主打韩语并兼顾英语。官方称编程和智能体任务上与 Meta 的 Muse Glimmer 30B 相当，且更快、更省内存。是混合架构落地的一个新样本，也算从零训练的案例。
[aihot 条目](https://aihot.news/items/vs466cl8vloyg91m98yea29b4)

### Anthropic：单一 Agent 往往胜过多个子智能体
基于多个企业部署经验，Anthropic 建议评估合并子智能体：按需加载上下文的单一 Agent 在质量、成本、延迟上常优于多智能体，一次对比里快了约一倍。这对 harness 设计是个很实用的反直觉结论。
[aihot 条目](https://aihot.news/items/fa3deahwrntv7809bl9zlahdt)

### LangChain 总结公司级 Agent harness 的五个组件
基于三个内部智能体，提炼出：驻留在用户已有场景（Slack）、区分代表用户与固定凭证的身份处理、全局与用户两级记忆、沙箱内代码执行，以及大量定时或事件触发的 ambient 运行。适合对照 harness 工程。
[aihot 条目](https://aihot.news/items/x4adef1qb3rctb29sr3xs3ear)
